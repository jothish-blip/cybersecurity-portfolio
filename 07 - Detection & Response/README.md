# Detection and Response

## Overview

This section of my cybersecurity portfolio documents hands-on activities completed while studying incident detection and response. The projects focus on identifying security incidents, analyzing network traffic, documenting investigations, examining malicious files, and applying incident response procedures.

Each activity demonstrates practical skills used by Security Operations Center (SOC) analysts throughout the incident response lifecycle.
